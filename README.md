# かこってみゅぜ (KakotteMuse)

Google の「かこって検索 (Circle to Search)」のように、画面を指で囲んで
その部分の画像を Muse アプリに送るための個人用アプリ。

**root が必要です** (KernelSU / Magisk 等で本アプリへの root 許可)。
送信先として Muse アプリのインストールが必要です。

## 特徴

- 指で自由になぞって囲む → 指を離すと即送信 (確認画面なし)
- 切り抜きと一緒に質問文「これ調べて」を自動で添えて Muse アプリへ直接送信
- Muse は小さな窓 (フリーフォーム) で開くので、元の画面を見たまま続きを聞ける
- 画面下のボタンから画面全体の送信も可能:
  - 左 (Muse アイコン): 画面全体を「これ調べて」で送信
  - 右 (Aあ): 画面全体を「翻訳して」で送信
- raw 撮影で高速起動 (PNG 圧縮・デコードを省略)
- 縦向き・横向き両対応
- レイヤー表示中は画面の四辺が青く光るので、視線を移さなくても
  起動中だと周辺視野で分かる (カットアウトで途切れないよう、
  各辺から約10%のグラデーションで表示)
- ステータスバーは黒帯にならず、背後の画面がそのまま見える

## 使い方

1. KernelSU / Magisk で本アプリに root を許可する (初回のみ)
2. 調べたいものが写っている画面を開く
3. 本アプリを起動する (アプリアイコン / クイック設定タイル)
4. 背後の画面がそのままレイヤーとして表示されるので、
   調べたい部分を指でなぞって囲み、指を離す
5. 囲んだ部分が質問文と一緒に Muse アプリへ送られる

囲まずに画面をタップすると、何も送らずに閉じます。

## 仕組み

- 起動した透明な Activity が、root の `screencap` を標準出力経由で
  実行し、背後の画面をメモリに取り込む (全画面画像は保存しない)。
  本線は raw 形式で、失敗した場合は PNG 形式に自動で切り替える
- 取り込んだ画像を同じレイヤー上に表示し、その上で囲む
  (本家と同じ「レイヤー」方式)
- 囲みは自由ストローク。その外接矩形 + 20dp の余白を切り抜く
- 切り抜きの受け渡しは MediaStore 経由
  (`Pictures/KakotteMuse/kakotte_crop.png` を常に上書きする。
  ギャラリーには最新の切り抜き1枚だけが残る)
- 送信は Muse アプリへの直接インテントが本線
  (受け口が見つからない場合は共有パネルにフォールバック)

以前は LSPosed モジュールとして SystemUI 内で撮影する方式を
試作したが、Android 16 / HyperOS では表示トークンの取得経路が
フレームワークから無くなっており、OS 依存の強い方式だった。
root 方式のほうが対応環境が広いため、こちらに一本化した。

検証環境: Xiaomi 17 Ultra (HyperOS 3 / Android 16, KernelSU)
